# ⚡ Smart Home Energy Consumption & Load Profile Analysis

A time-series data analysis project examining high-frequency (1-minute interval) household electric power consumption data to uncover energy usage patterns, seasonal demand spikes, and sub-metering efficiency.

---

## 📌 Project Overview

This project analyzes over 2 million sensor measurements from a residential power consumption dataset. Using Python (Pandas), the raw data is cleaned, interpolated, and resampled into hourly and daily aggregations to identify peak electricity demand times, voltage fluctuations, and appliance group energy footprints (Kitchen, Laundry, HVAC).
